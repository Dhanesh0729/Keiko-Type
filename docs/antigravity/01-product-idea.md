# Product idea and requirements

Keiko is a friendly typing practice application with an original anime-inspired SVG companion, expressive personalization, and useful performance analytics. Keep practice responsive and uninterrupted.

## Preserve existing behavior

- React 19/Vite, lucide icons, generated Web Audio sounds.
- Timed tests (15/30/60/120 seconds), word targets, quotes, custom text and untimed practice.
- Untimed practice ends on Escape or five seconds without a character edit. Exclude the inactivity grace period from scoring.
- Wall-clock deadlines reject late input, including after background throttling.
- WPM, accuracy, raw speed, reactive keyboard, corrected mistakes and per-second match graphs.
- Eleven themes, light/dark, RGB/hex accent and sound studio.
- Original companion appearance/personality controls and reaction previews; hands type and use the mouse. Hiding the companion fills the typing width.
- Unchecking divine preview restores ordinary eyes/eyebrows. Keep the removed green chest diamond removed.
- God Mode temporarily changes costume, sound and palette. Continuous pace drives decorative lettering: holding speed holds scattering; slowing reassembles; accelerating scatters again. Never scatter the typing passage. Ending/resetting restores prior preferences.
- Preserve selective God Mode rollback. Refresh its derived baseline after changing main.jsx; rollback must keep unrelated features.

## Requested launch work

1. Diagnose Clerk signup rejection and verify real signup/sign-in.
2. Optional secure cloud sync, separate guest/account caches, explicit guest import.
3. Export/import, deletion, automatic browser backups, bounded retention.
4. Mobile layouts, reduced motion, error reporting, public About/Help/Contact/Privacy.
